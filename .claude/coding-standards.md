# Coding Standards

Version: 1.0

---

# General

Readable code is preferred over short code.

Write code for humans.

Avoid clever implementations.

---

# Naming

Names must express intention.

Avoid abbreviations.

Classes use nouns.

Methods use verbs.

Variables use meaningful names.

---

# Methods

Small.

Focused.

Single responsibility.

Avoid more than one level of abstraction.

---

# Classes

Small.

Cohesive.

One responsibility.

High cohesion.

Low coupling.

---

# Comments

Do not explain WHAT.

Explain WHY.

Avoid obvious comments.

---

# Exceptions

Handle explicitly.

Never swallow exceptions.

Create meaningful exception messages.

---

# Validation

Validate input at system boundaries.

Protect Domain invariants.

---

# Logging

Log meaningful events.

Avoid excessive logging.

Never log passwords.

Never log secrets.

---

# Testing

Every important business rule should be testable.

Design for testing.

Avoid hidden dependencies.

---

# Refactoring

Leave the code cleaner than you found it.

Remove duplication.

Reduce complexity.

Improve readability.
